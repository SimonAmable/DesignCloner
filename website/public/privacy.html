Design Clone Privacy Policy

Last updated: August 29, 2026

Design Clone is a Chrome extension that copies a user-selected page element’s HTML and CSS to the clipboard for use with AI coding tools.

We do not collect, sell, or transmit user data. Serialization and clipboard writes happen on your device. The extension does not use accounts, analytics, ads, or a backend.

Website content: when you inspect and click an element, the extension reads that subtree in the current tab so it can copy markup and styles. That snapshot is not uploaded to us. You control what you paste elsewhere.

No preferences or page contents are stored with Chrome’s storage API.

Contact: use the support email on the Chrome Web Store listing.
